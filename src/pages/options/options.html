CC98 AI+ 设置

配置 AI 搜索用的 LLM、搜索预算，以及订阅提醒用的 Watch 后端地址。

LLM 配置（AI 搜索用）

Key 只保存在本机，只发给你填的 Base URL，绝不上传。
留 0 就不发送该参数，由模型自己决定上限。推理模型（deepseek-reasoner 等）的思维链也占这个额度，设小了正文会被挤掉。

搜索预算（控制消耗与速度）

内容过滤（AI 搜索去戾气）

数值越高过滤越严：会把更多带戾气 / 辱骂语气的回复从搜索结果里剔除。关掉「本地模型」则只靠脏话词表，更快但抓不准语气。

Watch 后端（订阅提醒用）

本地开发默认 http://127.0.0.1:8000。
